Used Libraries
---------------

The following libraries are used in the SimpliPFy project:

- `Lcapy <https://github.com/mph-/lcapy>`_ [LGPL-2.1 license]
- `SchemDraw <https://github.com/cdelker/schemdraw>`_ [MIT license]
- `Pyodide <https://github.com/pyodide/pyodide>`_ [MPL-2.0 license]
- `CodeMirror <https://github.com/codemirror/dev>`_ [MIT license]
- `QRCode.js <https://github.com/davidshimjs/qrcodejs>`_ [MIT license]
